# UPS Battery Alarm Runbook

## Symptoms

- Battery string voltage drift increases.
- Cabinet temperature rises.
- UPS self-test reports warning.

## Checks

1. Confirm UPS load percentage and redundancy state.
2. Check cabinet temperature and ventilation.
3. Inspect battery string voltage difference.
4. Review the latest self-test result.

## Mitigation

1. Keep UPS online and avoid unnecessary transfer.
2. Reduce thermal load or improve ventilation.
3. Schedule battery string inspection if drift remains high.
4. Escalate immediately if redundancy is lost.
